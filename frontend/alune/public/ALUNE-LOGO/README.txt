ALUNE LOGO ASSET PACKAGE
========================

Brand colors
- Deep teal: #14333A
- Muted gold: #B2A77E
- Warm off-white: #F7F5F0
- White: #FFFFFF
- Black: #000000

Included
- master/: editable SVG master
- primary/, white/, black/: logo variants
- monogram/: glasses symbol extracted from the original logo
- website-header/, website-footer/, loading-screen/: deployment-oriented exports
- favicon/: PNG favicon sizes and ICO
- social-media/: square transparent profile assets
- animation/: lightweight fade-in HTML/CSS example
- preview-sheet.jpg: light/dark comparison sheet

Technical notes
- SVG files contain editable vector paths and shapes, not embedded raster images.
- PNG exports use RGBA transparency.
- The loading animation fades in the unchanged SVG; it does not distort the logo.
- The monogram is the original eyeglasses symbol, not a newly invented mark.

Reconstruction note
The supplied reference is a 768x768 raster image. The vectors are a careful visual reconstruction from that reference, not recovery of the brand's original source vectors or font file. Some custom lettering contours and small overlaps may therefore differ from the exact original artwork. Review the preview against the source before production use.
